# Online Shopping

A simple Online Shopping web application developed using Python and Flask.

## Features

- Displays products
- Shows product prices
- Simple and user-friendly interface
- Built using Flask

## Technologies Used

- Python
- Flask
- HTML

## How to Run

1. Install Flask:
   pip install flask

2. Run the application:
   python app.py

3. Open the application in your browser.

## Project

This project is created for learning and practicing Python Flask web development.
